Plan de Estudios de Desarrollo Web

El sigueinte programa organiza los contenidos principales de un curso introductorio de desarrollo web.

Modulos del curso

  • HTML
    • Estructura basica de documentos
    • Etiquetas semanticas.
    • Enlaces y navegacion.

  • CSS
    • Selectores.
    • Modelo de caja.
    • Diseño reponsive.

  • JavaScript
    • Variables y funciones.
    • Eventos del navegador.
    • Manipulacion del DOM

Actividades

  1. Ejercicios individuales
    1. Crear una pagiona personal.
    2. Cronstruir un menu de navegacion.
  2. Proyecto final
    1. Diseñar la estructura del sitio.
    2. Implementar las paginas principales.
    3. Publicar el proyecto.
